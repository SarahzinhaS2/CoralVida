# CoralVida

Projeto de site para a ONG fictícia CoralVida, desenvolvido como parte da disciplina de Desenvolvimento Front-end. O projeto apresenta informações sobre a ONG, seus projetos de preservação dos oceanos e uma página de cadastro.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Páginas

- `html/index.html` — página inicial
- `html/projetos.html` — projetos de preservação
- `html/cadastro.html` — formulário de cadastro

## Instalação e execução local

1. Instale o Git.
2. Clone o repositório:

```bash
git clone https://github.com/SarahzinhaS2/CoralVida.git
```

3. Entre na pasta do projeto:

```bash
cd CoralVida
```

4. Abra a pasta no Visual Studio Code.
5. Execute o projeto pelo Live Server ou abra `html/index.html` diretamente no navegador.

O projeto é composto por HTML, CSS e JavaScript e não possui dependências externas que precisem ser instaladas por um gerenciador de pacotes.

## Build e testes

O projeto atualmente não utiliza uma ferramenta de build ou um gerenciador de pacotes. Também não possui uma suíte automatizada de testes configurada.

A verificação atual é feita executando as páginas no navegador e conferindo o funcionamento dos recursos implementados.

## Versionamento

O projeto utiliza Git e GitHub para controle de versão, seguindo uma estrutura baseada em GitFlow:

- `main` — versão principal e de lançamento.
- `develop` — branch de desenvolvimento.
- `feature/` — branches utilizadas para novas funcionalidades ou alterações específicas.

As mensagens de commit seguem o padrão Conventional Commits, utilizando tipos como `feat`, `docs` e `chore`.

A primeira versão do projeto foi registrada com a tag:

```text
v1.0.0
```

## Pull Requests

As alterações desenvolvidas em branches `feature/` são integradas à `develop` por meio de Pull Requests, mantendo o histórico das alterações organizado.
